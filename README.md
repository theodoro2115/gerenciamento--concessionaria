[Concessionária VIP

Sistema de gerenciamento para uma concessionária de veículos, desenvolvido em Java com o framework Spring Boot. O projeto permite o controle de estoque de diferentes tipos de veículos e a gestão de clientes (Pessoa Física e Jurídica).

🚀 Funcionalidades

•
Gestão de Veículos: Cadastro e listagem de Carros, Motos e Utilitários.

•
Gestão de Clientes: Suporte para clientes CPF e CNPJ.

•
Vendas: Registro de transações vinculando veículos a compradores.

•
Interface Web: Dashboard simples para visualização e interação com o sistema.

🛠️ Tecnologias Utilizadas

•
Linguagem: Java 11

•
Framework: Spring Boot 2.7.18

•
Gerenciador de Dependências: Maven

•
Frontend: HTML5, CSS3 e JavaScript (Vanilla)

📁 Estrutura do Projeto

O projeto segue uma estrutura simplificada para facilitar a manutenção:

•
src/main/java/com/vip/model: Classes de domínio (Veículos e Clientes).

•
src/main/java/com/vip/controller: Lógica de controle das operações.

•
src/main/java/com/vip/exception: Tratamento de erros customizados.

•
src/main/resources/static: Arquivos da interface web.
